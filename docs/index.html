Write and read .rkf documents

A .rkf file holds Markdown text and every image it references, in one file. Create one here, or open one you already have — it all runs in your browser.

or drop a .rkf file anywhere on this page

Install this as an app and your browser will open .rkf files when you double-click them.

Everything happens in your browser. Nothing is uploaded, and this page has no analytics, cookies or third-party requests.

A full editor, not just a viewer

Type straight into the page like a word processor, or edit the Markdown source side-by-side. Paste an image and it is embedded in the file. The same four modes and the same formatting toolbar as the VS Code extension.

HTML is allowed, safely

Markdown permits raw HTML, so <img src="assets/x.png" width="200"> works and points at the embedded image. It is rebuilt against an allowlist first, so a document cannot run script in your browser.

Checksums are verified

Every embedded image carries a SHA-256. The page recomputes each one with WebCrypto and reports any that do not match, along with dangling references and unused images — the same checks rk check runs.

No server involved

A .rkf is a ZIP, so the browser can both read and write one unaided, using DecompressionStream and CompressionStream. This page is static files on GitHub Pages.
