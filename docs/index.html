Project Spec

Read a .rkf document

A .rkf file holds Markdown text and every image it references, in one file. Drop one here to read it.

or click to choose one · or paste a link below

Or .

Your file is read in your browser. Nothing is uploaded, and this page has no analytics, cookies or third-party requests.

HTML is allowed, safely

Markdown permits raw HTML, so <img src="assets/x.png" width="200"> works and points at the embedded image. It is rebuilt against an allowlist first, so a document cannot run script in your browser.

Checksums are verified

Every embedded image carries a SHA-256 in the manifest. The viewer recomputes each one with WebCrypto and reports any that do not match, along with dangling references and unused images — the same checks rk check runs.

No server involved

A .rkf is a ZIP, so the browser can open it unaided: the central directory gives random access and DecompressionStream handles the rest. This page is static files on GitHub Pages.

Sharing a link

Add ?url= and a link to a .rkf to open it directly, for example ?url=welcome.rkf. GitHub blob links are rewritten to raw automatically. The host has to allow cross-origin reads.
